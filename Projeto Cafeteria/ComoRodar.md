## Instuçôes

Crie um arquivo .env na pasta back para colocar a url do seu banco, o banco esta rodando em Mysql
## Exemplo - .env {
   DATABASE_URL="mysql://root:senai@localhost:3306/cafeteria_dev"
}
Rode os Comandos nos Seguintes Diretorios.

## Diretorio Back 
npm run back

## Diretorio Front
npm run front
